# Электронный справочник «Первый курс»

Локальное веб-приложение для первокурсника. Для запуска не нужны сервер, аккаунт или установка библиотек.

## Запуск

Откройте `index.html` в актуальном браузере. Приложение использует `localStorage`: личные задачи, контакты, избранное и название колледжа хранятся в профиле браузера на этом устройстве. Очистка данных сайта удаляет их.

## Сборка Windows EXE

В проект добавлена оболочка Electron. Для сборки на Windows установи актуальную LTS-версию Node.js с официального сайта Node.js (в установщике оставь включённым npm), затем открой PowerShell в этой папке проекта и выполни:

```powershell
npm install
npm run dist
```

Готовые файлы появятся в папке `dist`:

- `Электронный справочник Первокурсника-1.0.0-x64.exe` — установщик с ярлыком в меню «Пуск» и на рабочем столе;
- `Электронный справочник Первокурсника-Portable-1.0.0-x64.exe` — переносная версия, не требующая установки.

Установщик и portable-версия могут быть не подписаны сертификатом, поэтому Windows SmartScreen может показать предупреждение.

Для запуска окна без сборки установщика используй `npm start` после `npm install`.

## Возможности

- 4 раздела и 12 памяток с поиском по заголовкам и тексту;
- избранное с сохранением между запусками;
- список личных дел со сроком, отметкой выполнения и удалением;
- локальный справочник контактов;
- настройка названия колледжа;
- экспорт и импорт резервной копии в формате JSON;
- адаптивная раскладка для компьютера и мобильного экрана.

## Настройка материалов

Содержимое находится в `data.js`. Меняйте описания, разделы и памятки там. Разметка — в `index.html`, оформление и адаптивность — в `styles.css`, взаимодействия и локальное хранение — в `app.js`.

Перед использованием в конкретном колледже проверьте тексты по его официальным документам и добавьте утверждённые контакты, ссылки и порядок получения справок. Точные расписание, сроки, суммы выплат и локальные правила в демонстрационных текстах не выдуманы.

## Портал SmartNation

В приложение добавлена ссылка на [портал College SmartNation](https://college.smartnation.kz/ru/mng/login), предоставленная пользователем. Справочник не пытается читать или хранить закрытые данные портала. На публичной странице также указана служба поддержки платформы Bilim Technology: +7 727 339 72 22 и +7 747 339 72 22; это контакты платформы, не конкретного колледжа.

## Резервная копия

Откройте «Настройки» → «Скачать копию». На другом устройстве откройте этот же справочник и выберите «Загрузить копию». Копия содержит только избранное, личные дела, контакты и название колледжа; статьи программы остаются частью приложения.
